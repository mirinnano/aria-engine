# V3 compatibility corpus

This directory is the migration boundary between the maintained C# runtime and
the independent Rust V3 runtime.

- `legacy-test-inventory.json` is generated by
  `scripts/classify-v3-legacy-tests.py`. It classifies test definitions as a
  behavior regression, legacy specification, fixture gap, or source-string
  dependency. The classification is a review queue, not an assertion that all
  listed behavior belongs in V3.
- `vertical-slice-inputs.json` is a green replay tape. The Rust test suite runs
  it through the Native and Web wrappers and requires identical VM, render,
  audio, UI, and runtime-command hashes.
- A legacy test becomes a V3 contract only after its behavior is represented by
  a platform-neutral source/replay fixture and the cross-runtime test is green.

Regenerate and verify the inventory with:

```bash
python3 scripts/classify-v3-legacy-tests.py
python3 scripts/classify-v3-legacy-tests.py --check
```
