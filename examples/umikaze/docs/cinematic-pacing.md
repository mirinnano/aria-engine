# 海風・演出時間設計

本文の正本は別作業ツリー `Desktop/Novel/src/` にある。この文書は本文を置き換える脚本ではなく、
正本内の非言語ディレクティブを Aria へ再生成するときの判断規約である。

## 判断順序

1. **正典性** — 語順、話者、曖昧さ、新しい事実を変えない。
2. **圧力の変化** — 情報、主導権、代償、外部からの視線のどれが変わったかを特定する。
3. **入力の所有者** — 読者に送らせるか、作品が時間を所有するかを決める。
4. **残像** — 演出の後で直前の一文の意味が増えないなら、その演出を置かない。

## 時間の語彙

- `pause breath 260–520`: 身体動作や小さな認識のあと。背景は残し、字幕だけを消す。
- `pause drift 620–1200`: 答えが返らない会話、決断、記録の変化。読者の送り後に作品が時間を取る。
- `pause drift 1400–1800`: 章に一度程度の不可逆な選択。場所を説明せず、同じ画面を残す。
- `pause ash 680–1400`: 景色が意味を決めすぎる瞬間。灰色へ退き、出来事だけを残す。
- `backdrop`: 人物の移動が物語上の位置を変えたときだけ使う。単なる時刻経過では変えない。
- `statement`: 作品が入力を2.4秒だけ引き取り、既存の一文を単色中央で自動提示する。常用しない。

待機中も RMenu と履歴は開ける。通常の送り入力だけを無効にするため、プレイヤーをアプリへ
閉じ込める時間ではなく、本文が一度だけ発話権を持つ時間として扱う。

## 章ごとの核

| 章 | 演出が所有する瞬間 |
|---|---|
| Day 0 | 死を見に来る者はいないというミオの発話、ノートを残す意図、カズキが金を持ち出す言い訳 |
| Day 1 | 写真を拒む顔と海だけの写真、母からの着信を切る夜 |
| Day 2 | 録音された風、自分で選んだ服、西へ行くという未決定 |
| Day 3 | 休ませたいカズキと松江へ行くミオの衝突 |
| Day 4 | 十四件の着信、顔ではなく海を見る携帯、離れない手 |
| Day 5 | 意図的だったかもしれないノート、「どうして来たの」、返せない「君は？」、病室への暗転 |
| Day 6 | 宿と距離の二者択一、尾道への二枚の切符、待合室を選ぶ夜 |
| Day 7 | 報道から逃げる移動、顔の写らない写真、「ここでいい」、閉じられる宿帳 |
| Day 8 | テレビを消した後の無景色、カズキへ渡される行き先の決定権 |
| Day 9 | 白い部屋と机へ戻る可能性、駅員が口を閉じる数秒、待合室へ戻る選択 |
| Day 10 | 行き先を見ない列車、空の水、「無意味な生」の一文、停車しても立たない身体 |

長い待機を均等に置かない。軽い会話や移動の説明には入力の応答性を残し、沈黙が人物間の
行為になった地点だけで時間を伸ばす。
