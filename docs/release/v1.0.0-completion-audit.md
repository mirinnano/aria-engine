# v1.0.0 Completion Audit

This audit maps the active goal to concrete artifacts and verification evidence.

## Objective Restatement

AriaEngine and the bundled umikaze work should reach v1.0.0 release-candidate quality:

1. Remove dead code and obsolete distribution paths.
2. Improve release build quality, distribution, effects, stability, speed, maintainability, and language design.
3. Reach minimum NScripter-quality compatibility without known important missing behavior.
4. Produce a distributable Windows build.
5. Reduce runtime crashes, critical bugs, and unhandled exceptions as far as current automated gates can cover.
6. Keep the codebase maintainable across engine code, scripts, assets, config, save data, build settings, README, and developer specs.
7. Record breaking changes.

## Completion Decision

The automated local v1.0.0 candidate path is complete for build, package, installer, replay, strict doctor, silent install/uninstall, headless chapter execution, and the script-owned UI visual baseline set. The full public-release goal is not complete until signing and any required human full playthrough gate is completed or explicitly waived.
